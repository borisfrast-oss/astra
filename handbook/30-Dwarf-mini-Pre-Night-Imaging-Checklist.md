# 30 – Dwarf mini Pre-Night Imaging Checklist (formerly dwarf3)

# Dwarf mini + Siril 1.4.4 + GraXpert + GIMP 3.2.4 Best Practices Handbook

---

# Objective

This checklist describes the complete preparation for an astrophotography night with the Dwarf mini.

Goal:

Prevent a lost night due to:

- incorrect settings
- dead battery
- incorrect focus
- incorrect filter
- missing calibration data

---

# 1. Before the Observation Night

## Check Weather

Verify:

- clouds
- transparency
- seeing
- humidity
- wind
- moon phase

---

Optimal:

```

clear sky

low wind

dry air

stable temperature

```

---

# 2. Target Planning

Decide beforehand:

```

What am I imaging?

What exposure?

Which filter?

How many frames?

```

---

Example:

```

M31

180 seconds

Gain 35

no filter

200 Lights

```

---

# 3. Prepare Storage

Check:

- sufficient storage space
- app current
- smartphone charged
- connection stable

---

Recommendation:

Before a long session:

```

at least several GB free

```

---

# 4. Check Battery

Before start:

```

Dwarf battery:
full

Smartphone:
full

Power bank:
optional

```

---

For long nights:

Plan power bank.

---

# 5. Select Location

Optimal:

- as dark as possible
- clear view
- stable foundation

---

Avoid:

- street lights
- window light
- direct light sources

---

# 6. Set Up Dwarf mini

Check:

## Stability

The Dwarf must:

- stand still
- not wobble
- not vibrate

---

## Alignment

Verify:

- target reachable?
- enough clear view?
- no obstacles?

---

# 7. Set Focus

One of the most important steps.

---

Before each session:

Check focus.

---

Verification:

Stars must be:

- small
- round
- sharp

---

Do not start with:

```

automatic trust without verification

```

---

- emission nebulae

Check before imaging:

```

correct filter active?
```

Check first image:

---

Verification:

- focus

correct now.

# 12. During Imaging

Do not constantly change settings.

---

Monitor:

- connection
- progress
- weather
- dew

---

Do not:

- move tripod
- change focus
- research target

---

# 13. Acquire Darks

After Lights:

Create Darks.

---

Important:

same conditions:

```

Exposure

Gain

Temperature as similar as possible

```

---

Recommendation:

```

10–30 Darks

```

---

# 14. Acquire Flats

If Flats are used:

After imaging:

Do not change:

- focus
- orientation
- camera settings

---

Flats require:

same optics.

---

```
Darks

Flats
```

# 18. Avoid Common Mistakes

---

## Too Few Frames

Problem:

* more noise
* less detail

Solution:

acquire more Lights.

---

## Too Long Exposure

Problem:

* stars clipped
* bright background

Solution:

shorter exposure.

---

## Wrong Filter

Problem:

Object loses signal.

---

## No Dark

Problem:

more hot pixels.

---

## No Flat

Problem:

gradients and dust.

---
